# Hanging-line alignment preview (v0.2.19)

The before pose is v0.2.18. The after pose keeps its translation and
minimizes shaft-tip movement while aligning the hanging-line endpoint
beneath the tip and keeping the sprite face visible. Model grip and scale are unchanged. This is an editor
approximation using Blockbench's pinned camera and base transforms.
The third-person sprite rotates 10 degrees in its plane around the grip,
with the accepted parent yaw and hand translation retained.
