# Rightward rod placement (v0.2.20)

The first-person orientation is unchanged. A translation along the editor
camera right axis shifts the grip 7.5% of screen width while preserving
height and depth. The shaded hotbar footprint is taken from the user
comparison. This is a Blockbench-camera approximation, not Minecraft.
Third-person sprite roll increases from 10 to 30 degrees around the grip.
